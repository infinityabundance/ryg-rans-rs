# ADR Template

Every significant decision in this repository gets an Architecture Decision
Record in `docs/adr/`.  A decision is significant when it is: hard to
reverse, load-bearing for correctness or interoperability, or the source of
a future "why is it like this?" question.

```markdown
# ADR-NNNN — <title>

Status: Accepted / Superseded-by-ADRNNNN / Rejected

## Context
What was the situation, and what forced the decision?

## Problem
What specifically needed to be decided?

## Alternatives considered
What else was evaluated?  Be concrete.

## Rejected alternatives
Which were rejected, and why?  (This section is as valuable as the
decision itself — it prevents re-litigating the same rejection.)

## Decision
What was chosen, precisely.

## Tradeoffs
What was given up, and what was gained.  Name both.

## Evidence
The code, tests, courts, receipts, benchmarks, or proofs that pin the
decision.  Cite paths and receipt IDs.

## Future implications
What future change would revisit this decision, and what would have to be
true for the revision to be right?
```
